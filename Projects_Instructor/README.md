# Projects - Instructor (Capstone)

**Project:** E-Commerce & Retail Analytics Deep-Dive

This is the single instructor-led capstone. It is fully solved.

## Files
- `Instructor_Capstone_Brief.xlsx` - scenario, datasets, deliverables, marking.
- `Instructor_Capstone_Solution.xlsx` - worked SQL queries + real result tables.

1. Teach the SQL in Week 3 against `Datasets/SQL/ecommerce.db`.
2. Demonstrate the Power Query + Data Model build in Week 2-3.
3. Hand the brief to strong students as a stretch; use the solution for live marking.
